# Nine Vicious Blocker

WE as a society are SICK and TIRED of Nine Vicious. This extension blurs (almost) ALL REFERENCES to him on X/Twitter until you choose to reveal them.

## Add the extension to Chrome

1. Download this repository and unzip it if necessary.
2. Open `chrome://extensions` in Chrome.
3. Turn on **Developer mode** using the switch in the top-right corner.
4. Click **Load unpacked**.
5. Select the unzipped `nine-vicious-blocker` folder—the folder containing `manifest.json`.
6. Open or refresh X/Twitter.

To keep the extension easy to access, open Chrome's Extensions menu (the puzzle-piece icon) and pin **Nine Vicious Blocker**.

## Update a locally installed copy

After replacing or editing the extension files, return to `chrome://extensions`, click the **Reload** button on the Nine Vicious Blocker card, and refresh X/Twitter.
